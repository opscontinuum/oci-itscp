# Citation audit

**Date:** 2026-09-01. **Scope:** every numbered entry in every `## References` section of `README.md`, `docs/01`–`docs/07` (excluding the index `docs/references.md`), `runbooks/RB-01`–`RB-05`, the five checklists, `evidence/README.md`, `scripts/dataguard/tnsnames-tuning.md` and `scripts/ebs/README.md`: 291 entries resolving to 107 distinct URLs plus 11 login-gated My Oracle Support notes that carry no URL.

**Method.** This is an adversarial audit: the default position for every entry was *refuted* until the page text proved otherwise. Each distinct URL was fetched once with `curl` (browser user-agent, redirects followed) and converted to plain text (HTML via BeautifulSoup, PDF via pypdf); pages that refused `curl` were retried through a browser-equivalent fetcher. "VERIFIED" means the specific statement in the entry's *Supports:* clause was found in that page's extracted text, not merely that the URL resolved; the supporting sentence is quoted in the table. "PARTIAL" means part of the clause is on the page and part is not, or the wording is materially different from what the document presents as a quotation. "NOT FOUND" means the clause is not in the page text. "CONTRADICTED" means the page says the opposite. "INACCESSIBLE" means the page could not be read (HTTP status, login wall, paywall); for those, the audit checked that the reason the document gives is true and that the body statement is hedged. After the entry check, the inline markers were read in the document body and the sentence or table cell each marker is attached to was compared with the cited page: exhaustively for `docs/03` §1 and §4, `RB-02`, `RB-04` and `docs/01` §4–§6, and for every load-bearing marker (numbers, *requires*, one-way-door claims, yes/no cells, licensing) in the other documents. Tool limits encountered: `www.oracle.com` price pages render prices by script and return HTTP 403 to the browser-equivalent fetcher; `blogs.oracle.com` and `mikedietrichde.com` return HTTP 403 to plain automated fetch (the latter was readable through the browser-equivalent fetcher); My Oracle Support redirects to a sign-in page; ISO and ITIL texts are paywalled; `esd.whs.mil` returns HTTP 403 to every method; `cnss.gov` required TLS verification to be disabled. All `docs.oracle.com`, `nvlpubs.nist.gov` and `csrc.nist.gov` pages returned HTTP 200 to `curl`.
